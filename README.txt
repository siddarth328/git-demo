SAI SIDDHARTH PORTFOLIO - HIGH PERFORMANCE EDITION
===================================================

An attractive, colorful, modern luxury portfolio website for Sai Siddharth.
Featuring all portfolio sections directly on the home page, an interactive car & automotive showcase, vibrant glowing gradients, glassmorphism UI, and smooth animations.

KEY FEATURES:
-------------
1. Complete Single-Page Home Experience (index.html):
   - Hero Section: High-impact introduction, interactive car showcase card, live status badge, and key metrics.
   - About Me: Background, BTech Computer Science education, interests, career goals, and automotive passion.
   - Skills & Tech Stack: Categorized into Web & Frontend, Languages & Backend, Database & Tools, and Embedded & AI.
   - Featured Projects: Detailed showcases of Blood Bank Management System, Wrong Route Prevention (Automotive Safety), and Fake Currency Detection (ML).
   - Car & Automotive Showcase: High-resolution car gallery with category filters (Supercars, Motorsport, Cockpit Tech), spec tags, and interactive zoom lightbox modal.
   - Contact Section: Contact cards (Email, LinkedIn, GitHub, Location) and an interactive contact form with instant validation & feedback.
   - Dynamic Navigation: Smooth scrolling with automatic active link scrollspy indicator and mobile drawer menu.

2. Visual & Theme Enhancements:
   - Deep obsidian background with ambient electric cyan, violet, and racing orange radial glows.
   - Glassmorphic translucent cards with subtle glowing borders and smooth hover lift animations.
   - High-resolution car photography included locally in the `images/` folder for offline and fast loading.
   - Floating "Back to Top" smooth scroll button.

DIRECTORY STRUCTURE:
--------------------
- index.html: Main comprehensive home page with all sections
- about.html: Dedicated About page
- skills.html: Dedicated Skills page
- projects.html: Dedicated Projects page
- contact.html: Dedicated Contact page
- css/style.css: Shared modern styling, colors, glassmorphism, and responsive CSS
- js/script.js: Scrollspy, mobile menu, car filters, image lightbox, form validation, and year auto-update
- images/: Curated high-resolution car photography assets

HOW TO RUN:
-----------
1. Open the folder in VS Code or any text editor.
2. Double click `index.html` to open in any web browser (Chrome, Edge, Firefox, Safari).
3. Or right-click `index.html` and select "Open with Live Server" in VS Code.
