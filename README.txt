SAI SIDDHARTH PORTFOLIO

Files:
- index.html: Home page
- about.html: About page
- skills.html: Skills page
- projects.html: Projects page
- contact.html: Contact page
- css/style.css: Shared styling
- js/script.js: Shared JavaScript

HOW TO RUN:
1. Extract the ZIP file.
2. Open the folder in VS Code.
3. Open index.html in a browser, or use the VS Code Live Server extension.
4. Click the navigation links to move between separate pages.

NOTE:
This is a static front-end portfolio. The JavaScript file handles small browser-side enhancements;
it is not a server-side backend. A real backend would be needed for features such as storing contact
form submissions in a database. Update the placeholder contact details in contact.html.
